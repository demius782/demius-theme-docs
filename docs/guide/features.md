# 功能指南

Demius 的功能文档按使用场景组织。你可以从这里选择需要的模块，也可以直接使用左侧目录跳转到具体配置。

## 内容展示

主页大图、轮播图、文章置顶、视频、相册、折叠面板、时间线和选项卡，适合构建内容丰富的博客首页与专题页。

## 页面与数据

侧栏组件、页脚、分类与标签、友链、装备、系列文章和沉浸式阅读，负责站点的信息组织和浏览体验。

## 互动与服务

音乐播放器、评论可见、说说、Umami 统计、打赏按钮、阅读进度与搜索引擎提交等模块可以按需启用。

## 选择建议

先完成核心内容和基础导航，再逐项开启视觉效果与第三方服务。这样更容易定位配置问题，也能控制页面加载成本。

::: tip 配置入口
每篇指南都包含配置位置、示例和常见问题。遇到版本差异时，请优先对照主题仓库当前分支的配置和更新日志。
:::
