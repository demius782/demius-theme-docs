# 开发维护总览

Demius 基于 Hugo 的模板、资源管线和数据文件构建。开发时可以把站点看成三层：内容层、站点层和主题层。

## 目录职责

- `content/`：文章与页面内容。
- `data/`：轮播图、友链、相册等结构化数据。
- `layouts/`：站点层模板覆盖。
- `themes/demius/`：主题默认模板、样式、脚本与静态资源。
- `static/`：站点层静态资源。
- `hugo.toml`：站点、菜单、主题和第三方服务配置。

## 覆盖规则

Hugo 会优先使用站点层的同路径模板覆盖主题层实现。因此定制功能时，优先在站点层新增或复制目标模板；只有通用能力才适合回写主题仓库。

## 推荐流程

1. 先确认页面类型和渲染入口。
2. 再确认数据来源与配置入口。
3. 使用最小改动完成模板或资源扩展。
4. 分别检查桌面端、移动端、明暗模式和无数据状态。
5. 更新对应文档和示例。

详细的文件对应关系和渲染链路见[原始开发维护指南](development-guide.html)。
